# Обжарка 7: сайт кофейни с моушен-графикой

Лендинг, где стакан собирают вживую: листаете напитки, выбираете размер, молоко и сироп, смотрите приготовление по этапам и получаете стакан со стикером с вашим именем.

Стек: Vite, React 18, TypeScript, Tailwind CSS, GSAP (ScrollTrigger), Framer Motion, Zustand, html-to-image. Шрифты (Literata, Manrope, Caveat, все с кириллицей) подключены пакетами fontsource, то есть это те же Google Fonts, но отдаются с вашего сайта.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # статическая сборка в dist/
npm run preview  # посмотреть сборку
```

Проверка стакана на всех напитках: откройте `http://localhost:5173/#/playground`.

## Как заменить фото, тексты, цены и напитки за 5 минут

Всё редактируется в `src/config/`, компоненты трогать не нужно.

| Что менять | Файл |
| --- | --- |
| Название, слоган, адрес, часы, телефон, соцсети, карта, текст «О нас», цвет бренда | `site.config.ts` |
| Напитки, рецепты (слои), цены, объёмы, виды молока и сиропов, позиции меню | `menu.config.ts` |
| Пути к фото | `images.config.ts` |

**Фото.** Положите файлы в `public/images/` с именами из `images.config.ts` (`hero.jpg`, `about-1.jpg`, `gallery-1.jpg`…, `menu/latte.jpg`…). Пока файла нет, показывается заглушка в цветах бренда. Логотип: `public/images/logo.svg`, он попадёт в шапку и на стакан.

**Размеры и форматы.** WebP или JPG. Обложка hero: ширина до 1920 px. Карточки меню и галереи: до 800 px. Лениво подгружаются все фото кроме обложки.

**Новый напиток.** Добавьте объект в `drinks` в `menu.config.ts`. Слои перечисляются снизу вверх: `espresso`, `milk`, `foam`, `syrup`, `water`, `ice`, `cream`, у каждого `amount` от 0 до 1 (сумма около 0.9) и необязательный `color`. Этапы приготовления собираются из рецепта сами: нет эспрессо, нет помола; нет молока, нет этапа молока.

**Цена.** Базовая цена по размеру лежит в `prices`. Наценки за молоко задаются в `milks`, за сироп и шот в `extras`.

**Цвет бренда.** `accent` и `accentDark` (для тёмной темы) в `site.config.ts`. Остальная палитра лежит в CSS-переменных в `src/styles/index.css`.

## Деплой

**Vercel:** импортируйте репозиторий, фреймворк Vite определится сам (build `npm run build`, output `dist`).

**Netlify:** build command `npm run build`, publish directory `dist`.

Сайт без бэкенда, заказ имитируется на фронте.

## Допущения

- Название «Обжарка 7», слоган и адрес выдуманы для примера. Меняются в `site.config.ts`.
- Акцент `#C2441F` темнее цвета из задания (`#D94F30`), чтобы белый текст на кнопках проходил контраст AA. В тёмной теме акцент `#F0714F`.
- Шрифт заголовков Literata вместо Fraunces: у Fraunces нет кириллицы.
- Карусель написана на Framer Motion (drag, стрелки, клик по соседнему стакану), Swiper не нужен.
- Валюта: рубли. Телефон, e-mail, ссылки на соцсети и координаты карты: заглушки.
- Если выбрать «Без молока» в напитке с молоком, молочный слой заменяется водой, а пена и сливки убираются.
- На мобильных конструктор открывается как bottom sheet: свёрнутая полоска с ценой и кнопкой «Заказать», по тапу раскрывается полный набор опций.
- Кнопка «Поделиться» сохраняет PNG-карточку со стаканом и именем.
- Анимации учитывают `prefers-reduced-motion`: волны и пар отключаются, приготовление ускоряется.
- Lighthouse не запускался, показатели Performance ≥ 85 и Accessibility ≥ 95 нужно проверить после деплоя.
